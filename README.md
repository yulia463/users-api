# Users API

Users API is a backend service for user management, providing registration, authentication, user listing, and blocking functionality.  
Tech stack: **Node.js**, **Express**, **TypeScript**, **TypeORM**, **PostgreSQL**, **JWT**, **Jest**.

---

## 🚀 Installation & Setup

## 1. Clone the repository

```bash
git clone https://github.com/yulia463/users-api.git
cd users-api
npm install
```

## 2 Install dependencies

```bash
npm install
```

## 3 Environment configuration
Edit a .env file in the project root.
Adjust database credentials according to your local setup.


## 4 Running the project

```bash
npm run dev
```
## 5 Running the tests

```bash
npm test
```

## 6 Authentication
Authorization: Bearer `<token>`
